O download acontece no seu dispositivo. Nenhum dado é enviado à Central, ao WhatsApp ou ao GitHub.

Importante: abra esta página no mesmo aparelho, navegador e perfil que você usava no antigo editor. Se limpou os dados do site, os rascunhos talvez não estejam mais disponíveis.

Como usar depois

  1. Guarde o arquivo JSON exportado em local seguro.
  2. Abra o Painel Editorial original na pasta privada Radar_Cripto_EGI_Privado do seu repositório GitHub privado Meus_Projetos, baixe o HTML e abra offline.
  3. Escolha Restaurar JSON anteriormente exportado e selecione o JSON.
  4. Verifique o conteúdo e mantenha backups periódicos.

Se você nunca utilizou o editor público, não é necessário exportar nada. O editor funcional não está disponível nesta página.
